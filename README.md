# PalmCircuit

Landing page for PalmCircuit, an automation agency for small businesses in Nigeria.

Static site: one `index.html`, no build step, no dependencies. Fonts load from Google Fonts.

## Edit

Open `index.html` and change the text directly. Contact details are at the bottom, in the `#contact` section.

## Deploy

1. Push this folder to a GitHub repository.
2. Create a free project on Cloudflare Pages, Netlify, Vercel or GitHub Pages and connect the repository.
3. Build command: none. Output directory: the repository root.
4. Add your domain in the host's dashboard, then add the DNS records it shows at your domain registrar.
5. Wait for the HTTPS certificate to be issued (usually minutes), then open the domain to check.
